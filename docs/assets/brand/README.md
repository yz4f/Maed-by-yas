# T3N brand sharing image

`public/t3n-social-preview.png` is the official social-sharing image for `https://t3nn.wtf`.

The same source image is archived here as `t3n-social-preview-source.png` for version control and future updates. The public copy is referenced by the Open Graph and Twitter metadata in `app/layout.tsx`, so Discord and other platforms display this exact branded image when the website URL is shared.
