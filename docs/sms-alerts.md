# تنبيهات الموقع عبر SMS

التكامل جاهز مع واجهة [تقنيات SMS](https://dev.taqnyat.sa/ar/doc/sms/)، لكنه لا يرسل رسائل حتى يُفعّل حساب مزوّد الرسائل واسم مرسل معتمد. لا تحفظ رمز API أو رقم الجوال في المستودع.

## التفعيل على Railway

1. أنشئ حسابًا لدى تقنيات وفعّل اسم مرسل صالحًا للإرسال داخل السعودية. راجع متطلبات تفعيل API وعنوان الخروج من Railway إذا طلب المزوّد إضافته إلى القائمة البيضاء.
2. أضف المتغيرات التالية إلى بيئة خدمة الموقع في Railway:

   - `SMS_ALERT_TO`: رقم الجوال بصيغة `+9665XXXXXXXX` أو `05XXXXXXXX`.
   - `TAQNYAT_BEARER_TOKEN`: رمز API من حساب تقنيات.
   - `TAQNYAT_SENDER`: اسم المرسل المعتمد في الحساب.
   - `SMS_ALERTS_ENABLED`: القيمة `1` بعد اكتمال الإعداد.

3. أعد نشر الخدمة، ثم جرّب تسجيل دخول جديد وراجع استقبال الرسالة في الجوال ولوحة المزوّد.

ترسل الخدمة رسالة قصيرة لكل حدث يُكتب في سجل النظام، إضافة إلى الدخول والخروج عبر Discord. تشمل أمثلة ذلك تسجيل عضو جديد وطلبات الرستات وتفعيل المفاتيح. لا تتضمن الرسائل المفاتيح أو عناوين IP أو محتوى محادثات الدعم؛ التفاصيل الكاملة تبقى في سجل الإدارة. لا تُرسل نبضات حضور المستخدم أو مجرد فتح صفحة، لأنها ليست أحداثًا في السجل.

قد يحاسب مزوّد SMS على كل رسالة أو مقطع، لذلك راقب عدد الأحداث والتكلفة قبل ترك التنبيهات مفعّلة على مدار الساعة. لإيقاف الإرسال دون تغيير الشيفرة، غيّر `SMS_ALERTS_ENABLED` إلى `0`.
